# Warhammer App

The complete application is in [prototype](prototype/README.md).

Install Node.js 24 LTS and Git, clone this repository, then run:

```sh
cd prototype
npm ci
npm run dev
```

Open http://localhost:5173. See the app README for tests, device limitations and source provenance. The prototype folder contains real tracked files, not a submodule.

The published Site is separate; GitHub pushes do not deploy it.
